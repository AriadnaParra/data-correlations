# Drivers de comportamiento de clientes — NovaRetail+

Proyecto del bootcamp de Análisis de Datos de TripleTen (Sprint 8). Análisis correlacional de factores asociados al ingreso generado por cliente.

## Objetivo

Para NovaRetail+ (plataforma de e-commerce en Latinoamérica con millones de usuarios), identificar qué factores del comportamiento del cliente están más fuertemente asociados con el ingreso anual generado, de cara al cierre de 2024, apoyando al equipo de Crecimiento y Retención.

## Qué se hizo

- **Exploración de datos**: revisión de variables de comportamiento de usuario disponibles (frecuencia de compra, antigüedad, categorías de interés, etc.).
- **Análisis de correlación**: cálculo de correlaciones entre variables de comportamiento y el ingreso anual por cliente, identificando las relaciones más relevantes.
- **Interpretación crítica**: distinción explícita entre correlación y causalidad, evitando conclusiones de negocio no respaldadas por el análisis.
- **Visualización**: matrices y gráficos de correlación para comunicar los hallazgos de forma clara.
- **Recomendaciones**: identificación de los drivers de comportamiento con mayor potencial de impacto en ingresos, como insumo para decisiones de retención.

## Herramientas

Python — pandas, matplotlib/seaborn, análisis de correlación estadística, Jupyter Notebook.
